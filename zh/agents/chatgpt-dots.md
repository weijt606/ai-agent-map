一句话定位：dot 是 OpenAI 放在 ChatGPT 里的常驻 agent——每人一个，由 GPT-6 Astra 驱动，有自己的云端电脑和浏览器——它负责一件持续的事，自己决定什么时候跟进，在 ChatGPT、Slack、Teams 或电话里找你，并把具体活儿交给 ChatGPT Work 或 [Codex](codex.md)。

## 快速看点

| 项目 | 结论 |
| --- | --- |
| 厂商 | OpenAI |
| 路线 | 消费级个人 agent |
| 开源 | 否 |
| 形态 | ChatGPT 移动应用、桌面应用和桌面浏览器；也能在 **Slack、Microsoft Teams 和语音通话**里找到它 |
| 状态 | **2026-09-29** DevDay 发布；"逐步向符合条件的账号推出" |
| 在哪里跑 | 自己的云端电脑和浏览器；也能使用**一台**已连接的个人电脑（需该电脑上 ChatGPT 应用开着） |
| 模型 | **GPT-6 Astra**——OpenAI 的天花板模型（[profile](gpt-6-astra.md)） |
| 价格 | 个人可用于 **Pro（$100、$200 或 $500/月）**，仅限 18 岁以上；Business Premium 与 Enterprise 正在推出（Enterprise 需管理员开启） |
| 地区 | Pro 不覆盖**欧洲经济区、英国和瑞士** |
| 官方页面 | https://learn.chatgpt.com/docs/dots |

## 它和 ChatGPT 其他部分的区别

OpenAI 自己划了线：**Chat** 回答问题，**ChatGPT Work** 接一个委派任务（立即或定时），**Codex** 写软件，而**你的 dot** 长期盯着一件事，随情况变化想清下一步，并在对话之间主动跟进。dot 可以发起 Work 或 Codex 任务，用后台 agent 并行干活，还能稍后自己醒来——"不必为每次跟进都设固定日程"。

## 什么时候选它

- 你手上是一件**持续的责任**（一场活动、一个项目、一次续约），而不是一次性任务，你需要有个东西注意到变化、把需要拍板的事带给你。
- 你常驻 Slack 或 Teams：不管在哪儿跟它说话，都是同一个 dot、同一份记忆。
- 你已经在付 Pro，想让天花板模型来驱动你的 agent。

## 什么时候不选它

- 你在欧洲经济区、英国或瑞士，或者不是 Pro 用户。
- 你想要便宜的 agent：个人使用起步就是每月 $100。
- 你想要一个范围很窄的工具。dot 会用到你的 ChatGPT 记忆、它自己的私人笔记和所有已启用的插件；这种广度正是这个产品本身。

## 权限与数据

在某个动作影响你的账号或对外分享信息之前，自动审查会决定 dot 是可以继续、需要你批准，还是必须把这一步交还给你；你的指令和自定义规则可以再加限制，但"指令和自定义规则都不能覆盖内置的安全要求"。登录通过私密的登录表单完成，不经过对话，你也可以随时 **Take over**（接管）它的云端浏览器。它的后台调研是只读的；后续动作需要相应权限。本地图读到的文档没有写明 dot 专属的训练条款。

## 结论

三大助手的 agent 里野心最大的一个——天花板模型、自己的电脑、多渠道——也是三家里最贵的一个，并且对欧洲关闭。如果你是欧洲以外的 Pro 用户，它是第一个该评估的；如果不是，它目前还不是你能做的选择。
