一句话：GPT-6 Astra 是 OpenAI 当前的前沿模型，2026 年 9 月 3–4 日发布——相对 GPT-5.6 家族是一代跃迁，标价与 [Claude Fable 5.1](claude-fable-5.md) 完全一致，而且面向公众发布的是一个刻意受限的版本。

## 一眼判断

| 项目 | 结论 |
| --- | --- |
| 厂商 | OpenAI |
| 路线 | 前沿 agentic 模型——OpenAI 侧当前的天花板 |
| 是否开源 | 否 |
| 最适合 | agentic 执行、计算机与浏览器操作、长上下文检索、编码工作流 |
| 主要代价 | $10 / $50 每百万 token；长上下文档涨到 $20 / $75（阈值据报为 272k 输入 token） |
| 公开版本 | 受限——拒绝部分网络安全类 prompt；进阶能力走 Daybreak Blue 审批 |
| 官方公告 | https://openai.com/index/gpt-6-astra/ |
| API 价格 | https://developers.openai.com/api/docs/pricing |

## 为什么要收录

本地图追踪模型层，是因为模型决定了架在它上面的每个 agent 的能力上限。OpenAI 这一侧的上限两个月内动了两次——**7 月 9 日的 GPT-5.6**，然后是**9 月 3 日的 GPT-6 Astra**——两次都改变了 [Codex](codex.md)、ChatGPT、GitHub Copilot 以及任何基于 API 的 agent 能做什么。

Astra 还是本地图记录到的第一个"**公开版本本身就是受限版本**"的前沿模型。这是选型事实而非脚注：你能构建什么，取决于你拿到的是哪个版本。

## 什么时候选它

- 你要 OpenAI 最强的 agent 用模型——官方定位是在编码、数学、以及驱动计算机和浏览器上达到 SOTA。
- 你的 agent 主要败在**跑偏**：这次发布的说法集中在"保持专注、守住任务边界、把多步流程做完"，而不是刷分。
- 你需要一次性吃下超长上下文——窗口据报约 105 万 token，最大输出 128k。
- 你已经绑定 OpenAI 生态，要的是上限而不是价格阶梯。

## 什么时候不选它

- **你的工作触及攻防安全或相邻研究。** 正式开放的版本会直接拒绝部分网安类 prompt，扩展能力要过 Daybreak Blue 审批——就是 2026 年 8 月 GPT-5.6-Cyber 落地时用的那道闸。
- 你的 prompt 经常超过 **272k 输入 token**：越过这条线，输入涨到 $20/M、输出涨到 $75/M。一个长上下文的 agent 循环可能在没人拍板的情况下就跨过去了。
- 你对成本敏感：[GPT-5.6 Terra](gpt-5.5.md) 的 $2/$12 和 Luna 的 $0.20/$1.20 足够干常规 agent 活，档位阶梯仍然是 OpenAI 侧的成本杠杆。
- 你要开放权重、自托管，或者一个能长期钉住不变的模型。

## 能力形状

| 维度 | 判断 | 说明 |
| --- | --- | --- |
| Agentic 执行 | 很强 | 守住任务边界、完成多步流程是这次的头条说法 |
| 计算机与浏览器操作 | 很强 | 被点名为相对 GPT-5.6 的主要提升轴 |
| 编码 | 很强 | 截至 2026 年 9 月，DeepSWE v1.1 74.1% |
| 长上下文 | 很强 | 约 105 万 token——但分两个价格带，见下 |
| 网络安全（公开版） | 受限 | 能力存在；出厂默认拒绝其中一部分 |
| 开源 / 自托管 | 无 | 完全闭源 |

**来源说明。** 两点要标出来。其一，OpenAI 发布材料引用的是 **DeepSWE v1.1**，不是 SWE-bench Verified，因此发布时不存在与 Claude 的同口径对比——本地图不自己造一个；你在别处看到的 Astra 对 Fable 的 SWE-bench 表格，请先确认那些数字来自厂商还是第三方榜单。其二，写本页时 `openai.com` 无法直接抓取：下面的**价格与“短/长上下文两档”这个结构是一手的**（OpenAI API 价格页），而 **272k 这条线、约 105 万的窗口、128k 最大输出来自二手报道**，出现的地方都已标注。

## 价格结构（一手，2026 年 9 月）

| 档位 | 短上下文 输入/输出 | 长上下文 输入/输出 | 缓存输入 |
| --- | --- | --- | --- |
| **GPT-6 Astra** | $10 / $50 | $20 / $75 | $1 |
| GPT-5.6 Sol | $4 / $20 | $8 / $30 | — |
| GPT-5.6 Terra | $2 / $12 | $4 / $18 | — |
| GPT-5.6 Luna | $0.20 / $1.20 | $0.40 / $1.80 | — |

有三点要带进预算：

1. **长上下文加价是那个坑。** 越过长上下文阈值（据报为 272k 输入 token）后，整个请求换价。Anthropic 的 1M 窗口在整窗内按标准价计费，所以两家现在差的是**形状**，不只是水位——见 [Opus 5 的档位阶梯](claude-opus-5.md)。
2. **Astra 与 Fable 5.1 标价完全相同**（$10/$50）。真正拉开差距的是缓存：Fable 5.1 缓存读 $0.25/M，Astra $1/M——对长会话 agent 来说，账单正是在这里堆起来的。
3. **Fast 模式是 2 倍价**（输出 $100/M），且在 EU 数据驻留下不可用。Batch 半价；多数模型上 Flex 与 batch 同价。

## 在哪里能用

- **ChatGPT**——付费档，受限的公开版本。
- **API**——按上表价格。
- **Codex**——产品边界见 [Codex profile](codex.md)；其下的模型 7 月换成 GPT-5.6 家族，Astra 是当前的上限。
- 分批放量：9 月 3 日限定伙伴预览，9 月 4 日付费用户，随后扩展到 API 与云。

## 与 GPT-5.6、GPT-5.5 的关系

[GPT-5.5](gpt-5.5.md) 作为 2026 春季参照点留在本地图里，模型血统表也放在那个 profile。简版：GPT-5.5（4 月）→ GPT-5.6 Sol/Terra/Luna（7 月 9 日）→ GPT-6 Astra（9 月 3 日）。Astra 发布并不意味着分档家族消失——它仍是控成本的那条路，而 Sol 的促销价 $4/$20 至少延续到 2026-11-21。

## 结论

Astra 让 OpenAI 重新有了一个清晰的天花板，也把前沿决策拉回成"两家、同一个标价"的对比。别看标价看细则：272k 换价线和 4 倍的缓存读差价，对真实 agent 账单的影响远大于那张 benchmark 表。另外，在设计任何安全相邻的东西之前，先确认你拿到的是哪个版本。
