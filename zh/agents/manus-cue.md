一句话定位：Cue 是 Manus 推出的个人 agent 独立应用，**每个 agent 都有自己的邮箱、电话号码、钱包和电脑**——所以它能给人发消息、在你设定的预算内付款、替你接电话——这让它成为这份名单里在你自己的账号之外触达最广的 agent。

## 为什么收录

这里其他所有 agent 借用的都是*你的*身份：以你的身份登录、从你的邮箱发信、用你的卡付钱。Cue 给 agent **一个它自己的身份**。这是一个不同的设计决定，后果也不同，值得放在地图上作为光谱的另一端。

## 什么时候选它

- 你想要一个能跟外界打交道、**又不暴露你自己的邮箱、号码或银行卡**的 agent：它用自己的邮箱和号码发消息，在你的预算内用自己的钱包付款。
- 你想要带书面摘要的来电筛选——它能替你接电话并给你留一份摘要。
- 你想让几个 agent 围绕同一个目标工作：把它们拉进一个群聊，它们会互相交接任务。

## 什么时候不选它

- 你需要价格、模型或地区方面的承诺：一手来源里都还没有。
- 你拿不到邀请码——名额有限，先到先得。
- 你不能接受一个**以独立一方身份**面对他人的 agent。用它自己的身份发出的消息和付款仍然出自你的指令，而对面的人未必知道自己在跟 agent 打交道。

## 权限与数据

Manus 的发布文章说预算和方向由你设定；但没有为 Cue 写明审批模型、数据保留或训练条款。App Store 页面链接到的是 Manus 的通用隐私政策。把它当作一个治理规则还没写下来的抢先体验产品。

## 结论

这份名单里设计最独特的一个——agent 作为独立一方，有自己的电话和钱包——也是文档最少的之一。适合拿低风险的杂事试一试；在条款写成文字之前，还不适合交给它一笔真实预算。
